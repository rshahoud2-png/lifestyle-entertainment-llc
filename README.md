# Lifestyle Entertainment LLC

A Vercel-ready React/Vite website for Lifestyle Entertainment LLC.

## Deploy on Vercel

1. Import this repository into Vercel.
2. Keep the detected framework as Vite.
3. Use `npm run build` as the build command and `dist` as the output directory.

## Local commands

```bash
npm install
npm run dev
npm run build
```

## Notes

The design is an original implementation inspired by the editorial pacing, bold type, and immersive interaction style of high-end digital studio websites. It does not copy source code or protected assets from the reference site.
